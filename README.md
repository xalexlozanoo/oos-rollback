- Extract stock images in a directory and cd into it.
- `git clone https://github.com/xalexanoo/oos-rollback.git flash && cd flash `
- Reboot to fastbootD
- `./flash.sh`
- If everything flashed successfully **(check properly)**, do `fastboot reboot bootloader`
- `fastboot -w`
- `fastboot reboot`
